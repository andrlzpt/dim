3D-ASCII ABSTRACT FIRST PERSON HORROR GAME

# minimap

| Symbol | Meaning |
| :---: | --- |
| `@` | Your current room |
| `>` `v` `<` `^` | Facing east, south, west, or north |
| `o` | Open room without pillars |
| `2` | Room with two pillars |
| `4` | Room with four pillars |
| `-` or `\|` | Connection between visited rooms |
| `N` | North |
| `*` | Bearing toward the active checkpoint |
| `X` | Visited room containing the checkpoint |
| `V` | Room containing a reached checkpoint |
